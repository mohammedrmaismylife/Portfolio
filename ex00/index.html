About me

I'm a software development student who enjoys turning an empty file into something people can actually use. I learned the web from the ground up: semantic HTML first, then CSS layout, then JavaScript to make pages react to the person using them.

I like understanding why code works, not just copying what works. When something breaks, I read the error, reproduce it, and fix the cause instead of the symptom.

Right now I'm improving my JavaScript and learning how to write code that other people can read.
